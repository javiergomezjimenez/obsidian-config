# obsidian-config

Configuración compartida de Obsidian, enlazada desde cada vault.

## Común a todos los vaults

- `appearance.json`, `hotkeys.json`
- `themes/`, `snippets/`
- `plugins/`

## Perfiles

- `profiles/notes/app.json` — ajustes de editor para los vaults de apuntes
  (adjuntos en `./assets`, notas nuevas en la carpeta actual).

## Propio de cada vault

Cada vault guarda en su `.obsidian/` lo que le es propio: `graph.json`,
`bookmarks.json` y `workspace.json`.
